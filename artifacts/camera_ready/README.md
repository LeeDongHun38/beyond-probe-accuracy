# Camera-ready experiment artifacts

Use the filenames below relative to this directory. The table numbers refer to the [final paper](../../paper/Beyond%20Probe%20Accuracy.pdf). Protocol files retain the run-time table names and identifiers. For example, v2 called the scale-normalized sweep “Table 14”; it appears as Table 12 in print. Archived cache locators identify inputs on the original compute system. Protocol hashes in run records refer to the original snapshots, before path prefixes were shortened for release.

| Paper result | Inputs and scope |
|---|---|
| Split, layers and MD stability (Tables 1, 3, 9, 11) | v1 documents overlap, alias collisions, sensitivity estimates and unresolved checks on the earlier split. v2 contains the final TriviaQA split, question-group half assignments, training AUROC profiles, FP16 projection scores and D0–D3 directions. ARC-Easy and CommonsenseQA retain their original partitions. |
| Estimator comparisons (Figure 2, Tables 12–14) | v2 contains the raw fits, scale-normalized LR results, and the paired score/bootstrap arrays for all 66 comparisons. v4 adds standardized D4/D5 results and vectors for the three smaller models, participation ratios and fixed-α effects. The v2 Llama scalar-RMS λ=1 checkpoint is the normalized direction used for the paired intervention. |
| Fixed and matched steering (Figure 3b, Tables 15–17) | v4/figures/figure3b_input.csv combines all three datasets. v3/C contains the 7–8B matched-r effects, paired comparison and question-cluster intervals. v4 adds the two 14B matched-r effects on TriviaQA. Per-model readout metadata records the expanded Yes/No token set for Qwen2.5-14B. |
| Fixed-α isotropic null (Figure 3a, Table 18) | v4/figures contains the ARC-Easy and CommonsenseQA null draws for 20 sides. v5 contains all 1,270 direction-by-side effects for the 10 TriviaQA sides. The builder takes the absolute effect **after** averaging over seeds, then corrects all 30 p-values together. |
| Matched-r controls (Tables 19–20) | v3/C contains the three smaller models’ isotropic and covariance/dose-matched controls. v4/steering/qwen14/E7 files supply the other two isotropic sides. Table 19 uses one family of eight. Table 20 uses a separate family of 30. |
| Source and generation controls (Tables 21–24) | v4/E14_D1, E14_D2 and E15 contain template/length, gold-donor and own-generation results. E15 includes held-out projection scores and label audits, plus 1,000 random-direction AUROCs and correlations per model. The v4 TriviaQA bootstrap clusters repeated rows by normalized question for the answer AUROC and pre-answer correlation. |
| Transfer and thresholds (Tables 2, 25, 28) | v3/A contains the paired projections for all 30 TriviaQA model–precision conditions. v3/manifests records the independent calibration/evaluation question partitions and intervention samples. Table 2 uses all held-out pairs. Table 28 uses the evaluation half and a single FP16-calibrated threshold per model. Fractions in CSVs can be multiplied by 100 to obtain percentages. |
| Error geometry (Figure 4, Table 26) | v3/B contains observed energy and 10,000 permutation draws per condition. Qwen2.5-14B TriviaQA uses the v2 split. The other 20 conditions use the original controlled-panel draws. R1 and R50 share a 50-test BH family. R50−R1 uses its own 25-test family. Observed and null energies are fractions. |
| Margin diagnostics (Table 27) | v4/E13/margins_75.csv combines the 25 final TriviaQA conditions with 50 ARC-Easy/CommonsenseQA conditions. |

The release preserves pair and question IDs, fitted directions, score arrays, null draws and statistical summaries. Model weights, full hidden-state caches, scheduler logs and intermediate checkpoints were omitted. The v1 ledger includes failed, blocked and diagnostic cells from the earlier sensitivity audit. Its counts describe that audit's population.

The sibling directories `paper_sections/`, `sources/` and `stats_package/` hold earlier inputs and analyses. The final builders use selected ARC-Easy and CommonsenseQA rows from `paper_sections/`. The activation-matched 375-test geometry families belong to the earlier analysis.
